# Current User Flows — v5.0

### Flow 1: Browse live sellers and best deals
Homepage → Live Now grid → Click seller card
→ Watch stream → Buy via Stripe → Points earned (Phase 2)

### Flow 2: Discover local businesses
/discover → Search or browse category
→ View business storefront → See Google reviews + current deals
→ Book or buy via Stripe checkout

### Flow 3: Sign up as founding seller
/merchant → Enter business info
→ Connect Stripe → Storefront live in minutes
→ Listed on /discover → Go Live when ready

### Flow 4: Merchant manages their business
/dashboard → View sales and analytics
→ Update offers and pricing
→ Go Live (Phase 1) → View retention data (Phase 2)
