# Current User Flows

## Flow 1: Launch a business

1. User lands on homepage, sees textarea
2. Types an idea (or clicks a template chip)
3. Live preview appears as they type
4. Clicks "Start Selling →"
5. Auth modal (Google sign-in via Privy)
6. Wallet auto-created (Privy embedded Solana wallet)
7. AI generates storefront, offers, pricing (~30-60s)
8. Redirects to live project page
9. +25 DUM Points awarded

## Flow 2: Customer buys an offer

1. Customer lands on project page
2. Sees AI chat button ("Ask [Business]") — clicks or browses offers
3. AI recommends offers based on real data
4. Customer clicks offer → Stripe checkout
5. Payment processed → order created
6. +2 DUM Points to buyer, +2 to seller
7. Seller sees order in dashboard

## Flow 3: DUM Hub

1. User visits /hub
2. Points tab: see balance, buy via Stripe, see activity
3. Claim tab: see claimable amount, claim all to Solana wallet
4. Use tab: learn about discounts and tiers
5. Market tab: understand future DUM Market vision
6. Refer tab: get referral link, track clicks/signups

## Flow 4: AI Sales Assistant

1. Customer lands on project page with offers
2. Floating button "Ask [Business]" visible bottom-right
3. Click → chat opens with quick prompts
4. Customer asks question → AI responds using real offer data
5. Offer names in responses are clickable → scrolls to offers
6. Customer proceeds to checkout
